# Goodfolk design direction

Reference studied: https://shinta.framer.media/. Its hero uses a three-column layout, a central portrait media stack, a curved marquee, pill navigation, pink accents, and bold Open Sauce typography. The page moves through pain points, a word-reveal mission, alternating benefits, projects, sticky folder-tab services, comparison cards, process, testimonials, team, pricing, blog, FAQ, and two closing compositions.

Goodfolk retains expressive sans typography, confident photographic content, friendly geometry, and careful native motion. It changes the brand, voice, imagery, primary palette, hero composition, content hierarchy, capability format, portfolio proportions, process layout, pricing structure, studio presentation, and closing layout.

The new hierarchy is collage hero → dark manifesto and capabilities → asymmetric campaign gallery → interactive creative process → engagement rows → editorial studio image → two notebook stories → split FAQ → typographic closing. The brand uses near-white, charcoal, lime, and lilac, with locally hosted Manrope. No reference media or copy is shipped.

All CTAs use configurable links. No inquiry backend, fake submission, downloadable brief, newsletter service, or demo popup is included. Supporting routes are normal content pages.

Image direction: mint/cobalt movement portrait, coral/lavender drink portrait, and daylight documentary studio photo. Generation prompts are retained in work/goodfolk/image-prompts.md outside the buyer package.
