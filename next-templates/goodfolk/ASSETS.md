# Included assets

The three photographs are original AI-generated creative studies made for this template using the built-in image generation tool. They do not portray actual clients, staff, or commissioned campaigns. All visual subjects are fictional adults.

| File                         | Art direction                                                                                                 |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `public/images/creator.webp` | A candid creator portrait with a green skateboard, cobalt T-shirt, mint studio backdrop, and direct daylight. |
| `public/images/sip.webp`     | An expressive creator portrait with an unbranded drink can, lavender knitwear, and a coral backdrop.          |
| `public/images/studio.webp`  | Documentary-style creative collaboration around a studio table with natural window light.                     |

The images are bundled as optimized WebP. Use them as illustrative studies or replace them with your own properly licensed portfolio and team photography before presenting the site as a real business.

The brand mark, notebook covers, creative-process compositions, and decorative strokes are editable React, CSS, and SVG artwork included with the template. No asset from another template’s brand or reference site is included.
