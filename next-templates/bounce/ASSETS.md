# Assets

Every image in `public/images/` is original to this template. Replace them with your own before launch.

## Photographs and portraits

Generated with an AI image model (GPT Image 2.5) for this template and encoded as WebP. They depict fictional people. The six student avatars (`ama`, `kenji`, `ruth`, `arjun`, `valeria`, `karim`) were cropped from one generated grid.

| File | Prompt summary |
| --- | --- |
| `outcome-idea.webp` | A producer with headphones at a keyboard, magenta light |
| `outcome-drums.webp` | A producer tapping drum pads, cyan light |
| `outcome-mix.webp` | A producer turning a knob beside studio monitors, amber and violet light |
| `outcome-sound.webp` | A musician playing an analog synthesizer, lime light |
| `outcome-release.webp` | A producer at a laptop with city lights behind, blue light |
| `teacher.webp` | A producer and teacher in a recording studio, violet and blue light |
| Avatars | Six head-and-shoulders portraits, each lit in one of the page colours |

Every prompt asked for cinematic colour-lit photography and no text, logos, brand names or readable screens. The equipment shown is unbranded.

## Course platform screens

`platform.webp` and `platform-phone.webp` were rendered for this template from purpose-built interface layouts and encoded as WebP at 2× resolution. They show a fictional student project with fictional feedback, and use the avatar portraits above.

## Code assets

- Logo mark, favicon, track covers and waveforms: SVG and CSS in `components/ui/Brand.tsx`, `components/ui/Art.tsx` and `public/icon.svg`.
- Beat pad sounds: synthesized in the browser with the Web Audio API; no audio files.
- Icons: [Lucide](https://lucide.dev), ISC license.
- Fonts: Bricolage Grotesque, Figtree and Geist Mono, SIL Open Font License, served locally by Next.js.
