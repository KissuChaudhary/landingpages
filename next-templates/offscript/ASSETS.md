# Included assets

Four original AI-generated photographs were made for Offscript with the built-in image generation tool. They illustrate fictional adult subjects and concept campaigns, not actual clients, staff or commissioned work.

| File | Direction |
| --- | --- |
| `public/images/creator.webp` | Candid creator, cobalt shirt, green skateboard, mint backdrop and hard daylight. |
| `public/images/sip.webp` | Creator enjoying a drink, lavender knitwear, coral set and direct flash. |
| `public/images/studio.webp` | Illustrative studio collaboration at a table, documentary daylight. |
| `public/images/sidequest.webp` | Sneaker still life, lilac plaster, orange suede, tennis ball and cobalt sculpture. |

The images are optimized WebP. Replace them before representing subjects as your team or concepts as real client campaigns.

The mark, posters, pencil strokes, notebook covers and process compositions are editable SVG, React and CSS authored for Offscript. No asset from the reference site is included.
