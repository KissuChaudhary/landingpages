# Oddline design brief

Reference: https://scalelab.framer.website/ — inspected in the browser on 10 October 2026.

Retain the dark textured surfaces, electric green accents, campaign imagery, rounded containers, confident display type and restrained depth. Change the composition and hierarchy substantially.

The reference opens with a centered promise, a social-video wall and a statistics section, then services, case studies, pricing, platforms, benefits, process, reviews, FAQ and newsletter. Oddline leads with a left-aligned creative promise and asymmetric original photographic collage. Its work gallery comes first, followed by an editorial studio statement, capabilities, a process rail, two engagement options, FAQs and a solid chartreuse closing.

Positioning: distinctive creative direction for independent consumer brands. No invented ratings, follower counts or results. Original images carry concept-campaign labels. The brand uses an offset-square mark, starburst annotations, Space Grotesk/Inter, charcoal olive neutrals, chartreuse, cobalt and lilac.

Motion: scroll-linked collage depth, one-time reveals, progressive statement colour, a process rail, image zoom and in-place service/pricing transitions. No animation library, autoplay loop, simulated social statistics, form backend, downloads or application dialogs.

Buyer scope is one landing page, with direct CTA links and optional project URLs. Source was isolated into the unique Oddline folder after another concurrent session began using the initially selected Offscript name. Other session files were left in place.

Maintain the production demo with npm run export:demo. It exports under /demos/oddline and copies into the marketplace public folder. Buyer README and ASSETS contain no maintainer instructions.
