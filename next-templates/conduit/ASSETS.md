# Original assets

Every asset in this template was made for it. No image, logo, code or text was copied from any other site.

## Product screens

Six screens of a fictional product, designed as HTML for this template and rendered to WebP at twice their display size on October 10, 2026:

- `public/images/stage-build.webp`, `stage-orchestrate.webp`, `stage-observe.webp` — the agent builder, the workflow canvas and the run view, 2240 × 1440.
- `public/images/stage-build-phone.webp`, `stage-orchestrate-phone.webp`, `stage-observe-phone.webp` — focused phone versions of the same three screens, 1280 × 1040.

All names, people, records and figures in them are fictional. Replace them with screenshots of your own product.
