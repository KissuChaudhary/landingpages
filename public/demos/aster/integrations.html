Explore the creative tools and project workflows you can bring into your review space.

6 connection guides

Creative work

Design files

Keep a design reference and its version beside the review.

  • Selected file reference
  • Version and preview URL
  • Project association

Let the project owner choose which files can be read. Your production connector must respect file permissions and distinguish a preview from the editable original.

Creative work

Cloud storage

Bring approved project assets into a considered handover.

  • Selected folder reference
  • Asset names and links
  • File revision dates

Request access to the selected project folder. Keep private drafts outside the shared review and apply your service’s access controls to every asset.

Communication

Email

Invite a client to the right review, with a clear next action.

  • Recipient and project reference
  • Review destination
  • Notification preference

A live integration needs your own invitation and notification flow. Explain who receives a message and avoid including private project content in previews.

Communication

Team chat

Give an agreed revision a place in the studio’s daily workflow.

  • Selected team destination
  • Revision owner
  • Review link and summary

Choose the destination deliberately. Connect your own approval and notification service before sharing project feedback outside the workspace.

Planning

Calendar

Set aside time for the next review round.

  • Review session title
  • Participants and time
  • Project reference

Use the calendar provider’s consent flow and make availability permissions explicit. Check participants before creating or updating a live session.

Planning

Webhooks

Pass an approval or revision request into your project system.

  • Review decision and version
  • Event timestamp
  • Project and workspace reference

Validate event signatures and identity in your backend. Deduplicate events and keep credentials on the server when connecting production workflows.
