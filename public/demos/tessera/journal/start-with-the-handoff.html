WORKFLOW DESIGN / 4 minute read

Start with the handoff, not the model.

The best place to look for automation is often the space between two people, two tools or two steps.

Find the repeated explanation

Listen for information that gets copied, translated or explained more than once. A handoff that needs the same context every day is a useful place to investigate. Write down what enters, who receives it and what lets them take the next step.

Make the next step explicit

A workflow is easier to improve when its state is visible. What is ready? What is waiting? What needs judgment? Before introducing AI, determine whether a clearer connection or a smaller change to the process would resolve the friction.

Build around the exception

The routine path makes a satisfying demonstration. The exception path makes a dependable system. Define what happens when information is incomplete, access is missing or a person disagrees with the suggestion.
